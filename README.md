## 🚀 Featured Project

<div align="center">

  <a href="https://sokvia.vercel.app">
    <img src="https://img.shields.io/badge/SOKVIA-REAL--TIME%20COMMUNICATION-7C3AED?style=for-the-badge&labelColor=151022" alt="SOKVIA real-time communication" />
  </a>

  <br/><br/>

  **A full-stack communication platform built around real-time interaction.**

  Private and group chats, voice and video calling, media sharing, secure authentication, in-app notifications, and an administrator dashboard—all in one connected experience.

  <br/>

  <a href="https://sokvia.vercel.app"><img src="https://img.shields.io/badge/Explore%20SOKVIA-Live%20App-A78BFA?style=for-the-badge&logo=vercel&logoColor=white&labelColor=151022" alt="Explore the live SOKVIA app" /></a>

</div>

<br/>

| Layer | Technologies & Architecture |
|:--|:--|
| **Frontend** | React · TypeScript · Vite · Tailwind CSS |
| **Backend** | Python · FastAPI · Native TCP sockets |
| **Real-time** | Browser WebSocket · FastAPI gateway · TCP event routing |
| **Calling** | WebRTC audio/video · SDP & ICE signaling |
| **Storage** | MongoDB Atlas · Cloudinary |
| **Experience** | Group messaging · Media sharing · Notifications · Admin controls |

<details>
<summary><strong>🔍 What makes SOKVIA interesting?</strong></summary>
<br/>

- **Real-time architecture:** Native WebSockets connect the React client with a FastAPI gateway and Python TCP messaging layer.
- **Full communication stack:** Private messages, groups, media, voice notes, and one-to-one calling.
- **Secure by design:** Authenticated sessions, role-based access, and authorized media delivery.
- **Built for people:** Responsive layouts, dark/light modes, avatar cropping, and notification preferences.

</details>
